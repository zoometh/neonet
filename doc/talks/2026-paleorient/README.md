# Cypriot sickle-insert morphometric analysis

This directory contains the R script, input data, outline images, and generated outputs underlying the morphometric analysis of 113 Cypriot sickle inserts reported in the associated Paleorient manuscript.

## Contents

* `CYPRUS_SHAPES.R`: R script for outline processing, elliptic Fourier analysis, principal component analysis, clustering, chronological summaries, and figure generation.
* `data.xlsx`: Metadata and metric measurements for the analysed inserts, including specimen identifiers, site and phase attribution, median chronological dates, length, width, and thickness.
* `carpo.xlsx`: Archaeobotanical presence/absence dataset used for the contextual carpological synthesis.
* `img/`: Black-on-white JPEG outline images for the 113 analysed sickle inserts.
* `out/`: Figures, membership tables, descriptive summaries, and other outputs generated by the script.

## Reproducing the analysis

1. Download or clone this repository.
2. Open the `2026-paleorient` directory in RStudio, or run the script with Rscript.
3. Install the required R packages:

```r
install.packages(c(
  "dplyr",
  "ggplot2",
  "openxlsx",
  "RColorBrewer",
  "tidyr",
  "scales",
  "rstudioapi"
))

install.packages("Momocs")
```

4. Run `CYPRUS_SHAPES.R`.

The script identifies its own directory and reads the outline images from `img/` and the metadata from `data.xlsx`. Generated outputs are written to `out/`.

## Analytical workflow

The outlines were interpolated to 80 equally spaced coordinates and centred. Elliptic Fourier analysis was conducted using 20 harmonics without size normalisation. Principal component scores were used in the clustering workflow, together with scaled thickness, to summarise continuous form variation. The four resulting clusters are descriptive groups and are not intended as fixed typological morphotypes.

Chronological variation is represented through eight archaeologically defined phases. The distribution of insert lengths is presented descriptively by phase; no temporal regression model is fitted.

## Software

The script was developed in R using the Momocs package for outline analysis. The R version and package versions used for the final analysis are printed at the end of the script with `sessionInfo()`.
