Cypriot sickle-insert morphometric analysis

Technical report for the reproducible analysis of 113 complete used sickle inserts from Klimonas, Shillourokambos and Khirokitia. This page documents the computational workflow and the outputs generated by the R pipeline; it does not provide an interpretive discussion.

Methodological workflow

  1. JPEG outlines are imported as Momocs Out objects.
  2. Each contour is interpolated to 80 equally spaced coordinates and centred. No size normalisation is applied.
  3. Elliptic Fourier analysis uses 20 harmonics with norm = FALSE, retaining form variation.
  4. Principal component analysis reduces the Fourier-coefficient data. The first two principal components are used for the initial k-means clustering.
  5. A final four-cluster solution combines PC1, PC2 and scaled thickness. Cluster labels are then harmonised for reporting.
  6. Chronological summaries use the eight archaeologically defined phases supplied in data.xlsx. Length variation is displayed descriptively by phase; no temporal regression is fitted.
Functional orientation is defined from the distribution and orientation of cereal sickle gloss together with use-wear observations. The principal-axis alignment used in the standardized stack is a display transformation only; it is not used in the Fourier analysis, PCA or clustering.

Running the pipeline

  1. Clone or download the repository.
  2. Keep CYPRUS_SHAPES.R, data.xlsx and img/ together in this directory.
  3. Install the R packages listed at the beginning of the script, including Momocs.
  4. Run CYPRUS_SHAPES.R. Generated files are written to out/.
